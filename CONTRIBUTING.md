# Desenvolvimento

Use Python 3.12 ou superior em ambiente virtual. As alterações entram por pull request, em branches com o prefixo `guilherme/`.

Revise os arquivos antes de cada commit. Use mensagens curtas que descrevam o comportamento entregue. Mantenha dados pessoais, credenciais e arquivos de ambiente fora do repositório.

Execute os checks locais antes de enviar uma alteração. O repositório usa configuração TOML e scripts Python. A publicação de uma versão exige uma ação manual.
