# Evidência da aplicação

`execucao-demo.txt` foi gerado executando a aplicação .NET 8 e contém três relatos criados na sessão, listados por categoria, e a atualização de um protocolo.

Reproduza a demonstração na raiz do repositório:

```sh
dotnet run --project csharp/Zela.CitizenTech/Zela.CitizenTech.csproj < csharp/evidencias/entrada-demo.txt
```

Os dados de demonstração são fictícios e existem somente durante essa execução.
